# Lightmark API 测试看板

## 使用说明

- 每个模块必须按照统一结构描述：测试范围、主流程、备选流程、异常流程、验收标准、断言要求。
- 主流程用于 PR 冒烟和演示。
- 备选流程用于主干回归。
- 异常流程用于主干和夜间回归。
- 对数据库副作用敏感的断言，优先落在后端自动化测试中。

## 度假产品预订 API 测试

### 测试范围

覆盖目的地 / 日期 / 天数 / 标签筛选 -> 产品详情与 AI 文案 -> 创建订单 -> 取消险 -> 模拟支付 -> 退款完整链路。

### 主流程

筛选产品 -> 查看详情（含 AI 生成文案）-> 创建订单 -> 支付成功

### 备选流程

下单时复用常用出行人、购买取消险

### 异常流程

产品已下架、日期不可用

### 验收标准（测试通过条件）

- 多条件筛选（目的地 + 日期 + 天数 + 标签）返回正确产品列表
- 产品详情中 AI 文案字段返回非空且格式正确
- 创建订单时可选取消险，保费计算正确
- 支付成功后订单状态为“已支付”，取消险独立记录
- 退款时取消险自动触发，按规则返还
- 产品已下架返回 `410 Gone`
- 日期不可用返回 `400 Bad Request`
- 常用出行人复用功能正常

### 断言要求

- 断言 AI 文案接口返回值类型，例如 `description` 字段长度大于 20
- 验证取消险与主订单的关联关系，通过订单号关联
- 验证支付后主订单状态和取消险记录状态一致
- 验证退款时主订单和取消险退款记录同时更新

## 酒店预订 API 测试

### 测试范围

覆盖酒店列表筛选 -> 房型详情 -> 创建订单 -> 模拟支付 -> 发票申请 -> 评价与取消完整链路。

### 主流程

筛选酒店 -> 查看房型详情 -> 创建订单 -> 支付成功 -> 查询订单详情

### 备选流程

复用常用入住人、申请发票、提交评价

### 异常流程

酒店已下架、房型库存不足、重复支付

### 验收标准（测试通过条件）

- 城市、入住日期、离店日期、价格区间筛选正确返回酒店列表
- 房型详情返回房价、可住人数、房间设施等关键字段
- 创建订单后主订单与酒店明细表正确关联
- 支付成功后订单状态为“已支付”
- 发票申请成功写入发票申请记录
- 酒店或房型已下架返回明确错误
- 重复支付不重复加积分且不重复出票

### 断言要求

- 断言订单号与酒店订单明细通过订单主键关联
- 断言发票申请表中订单号、抬头、金额与订单一致
- 断言评价提交后酒店评价汇总数量或平均分更新

## 火车票预订 API 测试

### 测试范围

覆盖站点选择 -> 直达 / 中转查询 -> 座位筛选 -> 创建订单 -> 模拟支付 -> 退票 / 改签完整链路。

### 主流程

选择站点与日期 -> 查询车次 -> 选择座位 -> 创建订单 -> 支付成功

### 备选流程

学生票、儿童票、中转车次、常用乘车人复用

### 异常流程

无票、无效取票码、重复改签、订单状态非法

### 验收标准（测试通过条件）

- 直达查询返回符合条件的车次
- 中转查询返回两段车次和换乘信息
- 学生票和儿童票价格按规则计算
- 支付成功后生成取票码
- 退票后订单状态变更，退款金额计算正确
- 改签成功后旧订单失效、新订单生成，且仅允许一次改签
- 无票或无效取票码时返回明确错误

### 断言要求

- 断言取票码或 `ticketNo` 非空
- 断言退款金额与服务费符合退票规则
- 断言改签后新旧订单关联字段和状态变化正确

## 机票预订 API 测试

### 测试范围

覆盖航班搜索 -> 价格日历 -> 预览下单 -> 创建订单 -> 模拟支付 -> 退款完整链路。

### 主流程

搜索航班 -> 预览价格 -> 创建订单 -> 支付成功 -> 查询出票状态

### 备选流程

积分抵扣、附加服务、行李额、座位选择

### 异常流程

库存不足、支付方式非法、重复退款、产品不存在

### 验收标准（测试通过条件）

- 多条件搜索按出发地、到达地、日期、舱位、人数正确返回航班
- 价格预览正确计算税费、服务费、附加服务费和积分抵扣
- 支付成功后订单状态为“已出票”或等价状态
- 非法支付方式返回 `400`
- 缺少鉴权创建订单返回 `401`
- 产品不存在返回明确错误

### 断言要求

- 断言 `payAmount` 计算结果正确
- 断言航班订单明细中乘机人、舱位、附加项写入数据库
- 断言取消后库存回补

## 认证与权限 API 测试

### 测试范围

覆盖图形验证码 -> 邮箱验证码 -> 注册 -> 登录 -> JWT 鉴权 -> 管理员权限完整链路。

### 主流程

获取验证码 -> 注册 -> 登录 -> 带 token 查询当前用户

### 备选流程

通过邮箱或账号登录、普通用户和管理员分别访问接口

### 异常流程

验证码缺失、弱密码、邮箱域名不支持、未授权访问、权限不足

### 验收标准（测试通过条件）

- 注册成功返回用户基础信息
- 登录成功返回 token、角色、身份信息
- 受保护接口在携带有效 token 时返回成功
- 未携带 token 返回 `401`
- 普通用户访问管理员接口返回 `403`
- 验证码或密码不合法返回 `400`

### 断言要求

- 断言 token 非空
- 断言角色字段与身份字段一致
- 断言无权限时不写入后台日志或业务副作用

## AI 与外部接口 API 测试

### 测试范围

覆盖 AI 文案生成、智能助手、外部查询接口调用、失败降级与错误提示完整链路。

### 主流程

请求 AI 或外部服务 -> 返回结构化内容 -> 业务接口正常响应

### 备选流程

外部接口返回空数据、部分字段缺失但仍可降级返回

### 异常流程

超时、5xx、响应格式不兼容、鉴权失败

### 验收标准（测试通过条件）

- AI 相关接口在正常情况下返回非空内容
- 当外部接口可用时，系统能正确解析结果
- 当外部接口失败时，系统返回友好错误提示或降级结果
- 外部调用失败不应破坏主业务流程的事务一致性

### 断言要求

- 断言 AI 字段类型和结构正确
- 断言失败时响应结构仍符合统一响应格式
- 断言数据库中不会因为外部失败留下脏数据
