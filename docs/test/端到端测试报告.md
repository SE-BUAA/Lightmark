# **Lightmark 端到端测试报告**

## **测试报告**

本报告记录 Lightmark 旅游平台在公网环境中的浏览器端到端测试结果。测试从用户可见入口开始，覆盖页面跳转、权限控制和主要业务入口，并保存 Playwright 原始报告作为执行证据。

## **1. 测试概况**

- 测试日期：2026-08-28
- 测试入口：`https://lightmark.ortus.top`
- 环境：Windows、Node.js 24.16.0、npm 11.13.0、Chrome（Playwright Desktop Chrome）
- 测试工具：Playwright Test
- 参考：课程任务书“端到端测试覆盖全部业务场景”要求及既有测试文档格式。
- Playwright 配置和自动化脚本：'Lightmark/frontend/playwright.config.ts' 'Lightmark/frontend/e2e/smoke.spec.ts'

## **2. 自动化用例**

| 编号             | 场景                                     | 断言                                    |
| ---------------- | ---------------------------------------- | --------------------------------------- |
| E2E-001          | 健康检查并加载首页                       | `/api/health` 成功，首页标题正确        |
| E2E-002          | 登录入口校验                             | 登录页显示，空表单出现必填提示          |
| E2E-003          | 未登录访问火车票                         | 自动跳转 `/login`                       |
| E2E-004          | 未登录访问管理后台                       | 自动跳转管理员登录页或普通登录页        |
| E2E-005～E2E-017 | 用户中心、机票、酒店、火车票、度假、社区 | 注入普通用户 token 后进入并完成业务断言 |
| E2E-018          | 管理员产品和订单管理                     | 注入管理员 token 后验证后台数据变更     |

E2E-005～E2E-018 已写入脚本；需要有效测试账号、初始化数据及可用的 12306/AI 外部服务。通过 `E2E_USER_TOKEN` 和 `E2E_ADMIN_TOKEN` 注入，未配置时会明确跳过，不能当作通过。

## **3. 执行结果**

本次在公网环境实际执行 Playwright 全量端到端测试，18 个用例全部通过，累计耗时 44.7 秒；前端生产构建此前已通过（仅有包体积告警）。

安装依赖后先运行：

```PowerShell
cd frontend
npm install
npx playwright install chromium
npm run test:e2e
```

HTML 报告由 Playwright 生成，原始 JSON、HTML、截图、视频和 trace 默认保存在 `frontend/e2e-results/`。
