## 4. 复现步骤

### 4.1 公网环境准备

确认公网服务可访问：

```powershell
curl.exe -i https://lightmark.ortus.top/api/health
```
浏览器访问
```
https://lightmark.ortus.top/
```
确认首页能够正常加载。

### 4.2 安装测试依赖
在项目的 frontend 目录执行：
```
cd C:\code\code\project\SE-Lightmark\Lightmark\frontend

npm install
npx playwright install chromium
```

### 4.3 配置公网测试地址
```
$env:E2E_BASE_URL = "https://lightmark.ortus.top"
```
### 4.4 配置测试账号
认证业务需要注入专用测试账号 token：
```
$env:E2E_USER_TOKEN = "普通用户JWT"
$env:E2E_ADMIN_TOKEN = "管理员JWT"
```
token 仅保存在当前 PowerShell 会话，不写入代码、报告或 Git。
### 4.5 执行端到端测试
```
npm run test:e2e
```
正常结果示例：
```
Running 26 tests using 2 workers
26 passed (约 1.6 分钟)
```
### 4.6 查看测试报告
```
npm run test:e2e:report
```
或者：
```
npx playwright show-report e2e-results\html
```
HTML 报告默认地址：
```
http://localhost:9323
```
该地址仅在本机运行报告服务的 PowerShell 窗口保持开启时有效。
